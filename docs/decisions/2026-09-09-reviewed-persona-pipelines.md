## Remaining acceptance boundaries

Deterministic and installed-runtime checks do not establish live model compliance,
a complete shell security parser, all third-party tool coverage, attestation-key
custody, an exhaustive secret/history scan, native UI accessibility or crash-safe
automatic recovery. The journal intentionally leaves interrupted transactions for
operator reconciliation rather than guessing which concurrent files to delete.
Optional ASI-Evolve and external memory were not provisioned or certified.

Live model sessions are a separate acceptance gate; they are not inferred from
the deterministic role-selection and host-transport fixtures.
