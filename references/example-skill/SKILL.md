# example-skill

Capture the exact rejected action and hook output. Determine whether the action actually crosses the protected boundary; honor a real block and surface the authorized safe path or missing operator input.

For a suspected false positive, preserve the original input as a regression fixture and propose a narrow matcher correction. Include both that benign case and a real prohibited case to prove the guard still enforces its boundary. Apply a guard change only under explicit operator authorization, then rerun the original action through the intact guard.

Do not rephrase, split literals, stub, disable, or route around a hook to evade its rejection. A successful altered command is not evidence that the original block was a false positive.
